## D1 — Normalization & preprocessing
**Script:** `analyze_entropy.R` (calls `R/spanorm_lowmem.R`, `R/gene_universe.R`)
**Decision:** Raw Visium spatial transcriptomics data are loaded from `data/<sample_name>/`. Spots are explicitly subsetted to in-tissue spots (`in_tissue == 1`) using `spatial/tissue_positions.csv` *before* applying depth quality control. Visium hexagonal array lattice coordinates (`array_row` and `array_col`) are extracted from `tissue_positions.csv` and stored in the Seurat object's metadata for downstream spatial neighborhood construction (Stage 4). Spots are filtered using a minimum sequencing depth threshold of $nCount \ge 2000$ (matching the committed downsampling depth $D = 2000$ established in D2) and $nFeature \ge 250$, followed by coordinate alignment verification via `validate_imaged_coordinates()`. Features are filtered directly against the cohort Gene Universe (`results/cohort_qc/gene_universe.csv`, D5, 18,532 features in Seurat) without per-sample detection thresholding. A second depth gate is then applied on the matrix the entropy is actually computed from — post-universe, post-MT/ribosomal exclusion — dropping any spot whose remaining depth falls below $D = 2000$. Normalization is performed directly via `SpaNorm::SpaNorm()` using negative binomial modeling (`gene.model = "nb"`), `adj.method = "logpac"`, `df.tps = 6`, `lambda.a = 1e-04`, a fixed random seed (`set.seed(23)`), and default sampling fraction (`sample.p = 0.25`). An S4 method for `SpaNorm::SpaNorm` is registered on `Seurat` objects using public Bioconductor APIs (`SpatialExperiment` and `SummarizedExperiment`), eliminating private `:::` function calls. SpaNorm remains in the pipeline unchanged as the normalized input for downstream differential expression, module scoring, and visualization; only the entropy metric calculation uses rarefied raw counts (D2). QC metrics with explicit denominators (`Raw_Spots_Grid`, `Spots_On_Tissue`, `Spots_Post_Depth_QC`, `Spots_Post_Coord_Validation`, `Spots_Dropped_Entropy_Depth`, `Spots_Final`, `Pct_OnTissue_Retained`, `Raw_Genes`, `Genes_In_Universe`, `Genes_Detected`, `Pct_Universe_Detected`, `Mean_Percent_MT`, `Mean_Percent_Ribo`) along with entropy distribution metrics (`Mean_Rarefied_Entropy`, `SD_Rarefied_Entropy`, `Median_Rarefied_Entropy`, `IQR_Rarefied_Entropy`, `Min_Rarefied_Entropy`, `Max_Rarefied_Entropy`, `Range_Rarefied_Entropy`) are logged per sample to `results/analyze_entropy/<sample_name>_qc_metrics.csv`.
**Rationale:** `Load10X_Spatial(filter.matrix = TRUE)` loads all 14,336 grid barcodes when reading raw feature matrices. Explicitly subsetting on `in_tissue == 1` before depth QC ensures that QC denominators reflect true tissue area rather than unutilised slide background (2,623 off-tissue barcodes in sample1). Setting spot QC threshold to $nCount \ge 2000$ retains 99.63% of on-tissue spots in sample1 (11,666 of 11,713, dropping 25 shallow spots initially and 22 in the entropy depth gate) and aligns spot retention with the rarefaction depth $D = 2000$. Dropping the per-sample detection filter (previously $\max(20, \lceil 0.02 \times N_{\text{valid\_spots}} \rceil)$) ensures that every sample across the cohort is processed on the exact same feature space (the 18,532 universe genes), preventing sample-specific gene attrition from distorting cross-sample comparisons. Rarefaction already controls for sequencing depth variation and rare zero/low-count genes contribute minimally to entropy. The second depth gate guarantees $N_j \ge D$ on the matrix that is rarefied, making the $p_{ij} = y_{ij}/D$ formulation in D2 exact for every spot, and eliminating NA values for shallow spots in the entropy vector to avoid spatial weight matrix (`listw`) dimension mismatches. SpaNorm removes technical spatial noise and sequencing depth confounders while preserving spatial tissue architecture.
**Alternatives considered / rejected:** SCTransform and standard log-normalization were rejected because they do not explicitly model spatial coordinates or adjust for spatial technical autocorrelation. Setting spot QC to $nCount \ge 500$ while rarefying at $D = 2000$ with NA padding was rejected because it causes downstream spatial weight matrix length mismatches. Keeping per-sample detection thresholding was rejected because varying gene sets across samples break cohort-wide comparability and complicate feature accounting. Removing SpaNorm entirely was rejected: SpaNorm remains essential for gene-level spatial differential expression, module scoring, and expression visualization.
**Status:** implemented
**Review notes:** Updated spot QC depth threshold to $nCount \ge 2000$ (D2 revision) and added array lattice coordinates (`array_row`, `array_col`) to metadata. Dropped the per-sample 2% spot detection threshold, freezing the feature set to the cohort gene universe as-is (18,532 features in Seurat). Added distribution spread metrics (median, IQR, min, max, range) to the QC output table. Integrated cohort gene universe filtering (`filter_by_gene_universe()`). Replaced internal `:::` fitting architecture with direct `SpaNorm::SpaNorm()` method dispatch on `Seurat` objects. Pinned `bioconductor-spanorm=1.4.0=r45hdfd78af_0` and `bioconductor-spatialexperiment=1.20.0=r45hdfd78af_0` in `environment.yml`.

Memory note (implementation only, output unchanged): `SpaNorm:::normaliseLogPAC()` builds the whole $n_{\text{genes}} \times n_{\text{cells}}$ adjustment in a single expression, keeping roughly ten dense double matrices alive at once (`mu`, `mu.2`, two densified copies of the counts, `lb`, `ub`, `p`, and the `pmin`/`pmax`, `qnbinom` and `log2` temporaries). At sample1's dimensions one such matrix is 1.36 GB, so the step peaks near 13.6 GB and the OOM killer fires on a 15.1 GB machine. `R/spanorm_lowmem.R` supplies `normaliseLogPAC_lowmem()`, which performs the identical arithmetic in blocks of genes and writes into a preallocated output matrix; `enable_spanorm_lowmem()` installs it into the SpaNorm namespace via `assignInNamespace()` at the top of `analyze_entropy.R`. This is exact rather than approximate: given the fitted model every operation in the original is row-wise, and the single cross-gene quantity, `psi.max` = $\exp(\mathrm{median}(\log \psi) + 3\,\mathrm{mad}(\log \psi))$, is computed from the complete $\psi$ vector before any chunking. Verified with `identical()` against the unpatched kernel on a synthetic $700 \times 400$ fit at block sizes of 700, 125 and 1 genes, and end-to-end through `SpaNorm::SpaNorm()`; all four comparisons returned `TRUE` with a maximum absolute difference of 0. The public `SpaNorm::SpaNorm()` call, the model fit, `sample.p`, and every methodological parameter in this decision are untouched, and no package was added, removed or upgraded. The `logcounts` handoff in the `Seurat` method was also reordered to drop the `SpatialExperiment` reference before the dense-to-sparse conversion, so the dense and sparse representations are never alive at the same time. Measured on sample1 with `VmHWM`: whole-run peak RSS fell from an aborted run to 10.07 GB with this patch alone, and to 7.59 GB once the entropy helper was blocked as well (D2).

## D2 — Shannon entropy formulation
**Script:** `R/shannon_entropy.R` (called from `analyze_entropy.R`, `sweep_rarefaction_depth.R`, `diagnose_entropy_scaling.R`)
**Decision:** Spot-level transcriptional diversity is quantified using **Rarefied Shannon Entropy** ($H_{\text{rarefied}}$, stored as `entropy_rarefied`). Prior to entropy estimation, mitochondrial (`^MT-`) and ribosomal (`^RP[SL]`) gene families are filtered from the raw count matrix via `exclude_pattern = "^(MT-|RP[SL])"`. For each spot $j$ with filtered count $N_j \ge D$, counts are downsampled to a fixed target depth $D = 2000$ using `scuttle::downsampleMatrix(counts, prop = D / N, bycol = TRUE)` across $n_{\text{draws}} = 5$ independent downsampling draws. Random seed 23 (`set.seed(23)`) is initialized immediately prior to the draw loop. For each draw $k$, Shannon entropy is computed as $H_j^{(k)} = -\sum_{i} p_{ij}^{(k)} \log_2(p_{ij}^{(k)})$, where $p_{ij}^{(k)} = y_{ij}^{(k)} / D$. Spot rarefied entropy is the mean across draws, $H_j = \frac{1}{n_{\text{draws}}} \sum_{k=1}^{n_{\text{draws}}} H_j^{(k)}$, evaluated using column-blocked sparse matrix operations (`dgCMatrix`) to bound peak memory. The condition $N_j \ge D$ is enforced, not assumed: `analyze_entropy.R` gates spots on the post-exclusion column sums (D1) and `rarefied_entropy_matrix()` raises an error if any spot still falls short, because `scuttle::downsampleMatrix` would otherwise cap that spot's sampling proportion at 1.0 and return its full-depth entropy. Full-depth raw plug-in Shannon entropy ($H_{\text{raw\_plugin}}$, stored as `entropy_raw_plugin`) is computed directly on raw counts without downsampling to serve as an empirical baseline demonstrating depth bias. No alias columns are written: `shannon_entropy` previously denoted the SpaNorm log-scale entropy, so reusing that name for the rarefied metric would silently relabel the very metric this revision rejects.
**Rationale:** Stage 2 diagnostic analysis demonstrated that computing Shannon entropy on SpaNorm `logpac` normalized expression is a category error: SpaNorm's $\log_2(\text{qnbinom}(\cdot) + 1)$ compression flattens relative proportions $p_i \to 1/K$, causing normalized entropy to degenerate onto $\log_2(K)$ ($r = 0.9986$, $\rho = 0.9989$ against detected gene count $K$). While linear back-transformation ($2^x - 1$) resolves the log compression, unrarefied raw counts suffer from a depth-driven support ceiling ($\rho = 0.7311$ vs $nCount$, $\rho = 0.8187$ vs $nFeature$ in sample1): spots with lower sequencing depth mechanically observe fewer genes, capping plug-in entropy regardless of biological state. Rarefaction standardizes library depth across spots to $D = 2000$, completely breaking the near-deterministic feature ceiling ($\rho = -0.1330$ vs $nFeature$, $\rho = -0.2518$ vs $nCount$) while preserving true relative transcriptional diversity. Setting $D = 2000$ (rather than $D = 3000$) provides a large retention gain across shallower samples in the cohort (e.g., sample4: 81.48% vs 72.31%, +494 spots; sample21: 68.13% vs 62.45%, +390 spots) while spot rankings remain virtually identical ($\rho(2000, 3000) = 0.9658$ in sample1, $0.9374$ in sample4, $0.9531$ in sample21).
**Alternatives considered / rejected:**
1. *SpaNorm log-scale entropy:* Rejected due to complete degeneracy ($r = 0.9986$ against $\log_2 K$, acting as a relabelled gene counter).
2. *Linear back-transformation ($2^x - 1$) without rarefaction:* Rejected because it inherits the raw depth-driven support ceiling ($\rho = 0.7540$ vs $nFeature$, $\rho = 0.8602$ vs imputed support $n\_detected\_norm$).
3. *Alternative diversity estimators (Miller–Madow, Chao–Shen, James–Stein):* Rarefaction was selected as the most conservative, distribution-free standard for alpha-diversity standardization at unequal sequencing depth.
4. *Criticism of rarefaction ("Rarefying is inadmissible", McMurdie & Holmes 2014):* McMurdie & Holmes proved that rarefaction increases false positive rates in *differential abundance testing* due to discarded count information; their critique does not apply to *alpha-diversity estimation*, where standardization to equal sample size is statistically required.
5. *Success criterion:* Depth partly tracks physical cellularity per spot, so a slight residual depth correlation is biologically plausible. The revised success criterion is substantial reduction and complete elimination of near-deterministic detected-gene coupling ($\rho \approx 1.0 \to \rho \approx -0.13$), not an artificial collapse to exactly zero.

## D3 — Entropy–depth & covariate QC and stemness correlation tests
**Script:** `R/entropy_correlation.R`, `R/quality_confound.R` (called from `analyze_entropy.R`, `diagnose_entropy_scaling.R`, `analyze_stemness.R`)
**Decision:** Both parametric Pearson correlation ($r$) and non-parametric Spearman rank correlation ($\rho$) are computed alongside two-sided $p$-values, log10 $p$-values, 95% confidence intervals, and spot sample size ($N$):
1. In `analyze_entropy.R`: evaluates correlations for both `entropy_rarefied` (primary) and `entropy_raw_plugin` (baseline) against sequencing depth (`nCount`, `nFeature`) and the metabolic covariate `percent.mt`, outputting results to `results/statistical_tests/<sample_name>_entropy_correlations.csv` and a 6-panel publication scatterplot. `percent.ribo` is not a target because ribosomal probe counts are identically zero across the cohort (D2).
2. In `analyze_stemness.R`: evaluates biological correlation between `entropy_rarefied` (and `entropy_raw_plugin`) and `Stemness_Score1`, outputting results to `results/stemness_analysis/<sample_name>_stemness_correlations.csv` and `_spatial_comparison.png`.
3. In `analyze_stemness.R`, immediately after the stemness correlation: a **spot-quality confound control** (`run_quality_confound_check()` in `R/quality_confound.R`), run before any entropy–stemness association is treated as biological. It has three parts. (a) *Covariate correlations of the score itself* — `Stemness_Score1` against `percent.mt`, `nCount` and `nFeature`, written to `results/stemness_analysis/<sample_name>_quality_confound_covariates.csv` together with the same correlations for every entropy metric; these numbers were not in any output file before. (b) *Partial correlation* of each entropy metric against `Stemness_Score1` controlling for `percent.mt`, for $\log(nCount)$, and for both, in Pearson and rank (Spearman) form, written to `_quality_confound_partial.csv`. Both variables are regressed on the covariates via `stats::lm.fit` and the residuals correlated; significance uses $t = r_{xy \cdot z}\sqrt{(N-2-k)/(1-r^2)}$ on $N - 2 - k$ degrees of freedom and the CI the Fisher $z$ transform with $SE = 1/\sqrt{N-3-k}$ ($\sqrt{1.06/(N-3-k)}$ for the rank version), where $k$ is the rank of the covariate design. (c) *Subset sensitivity*, written to `_quality_confound_subsets.csv`: the zero-order correlations recomputed on the clean spots (`percent.mt < 10`), on their complement, and within each quartile of `percent.mt`. A four-panel figure (`_quality_confound_plot.png`) shows score vs `percent.mt`, entropy vs `percent.mt`, entropy vs score coloured by `percent.mt`, and the residual–residual scatter behind the partial correlation.
All correlation statistics reported anywhere in the project — zero-order, subset and partial — come from a single helper, `pair_correlation_stats()` in `R/entropy_correlation.R`, so the estimate, exact $p$, log10 $p$ and CI conventions cannot drift between tables.
All summary CSV outputs store exact unfloored double-precision floats for `Pearson_p` and `Spearman_p`. Both correlations carry log10 $p$-values computed via Student's $t$ cumulative distribution in log space ($\log_{10}(p) = \log_{10}(2) + \frac{\text{pt}(-|t|, \text{df}, \text{log.p = TRUE})}{\ln(10)}$) to eliminate saturation at `0.00e+00`. Pearson 95% CIs are derived from `cor.test`; Spearman 95% CIs use Fisher $z$-transformation with the Bonett–Wright standard error $\text{SE} = \sqrt{1.06/(N-3)}$.
**Rationale:** Evaluating both Pearson and Spearman metrics captures linear and monotonic associations while reporting exact unfloored $p$-values for meta-analysis across the 22-sample cohort. In sample1, evaluating stemness against rarefied entropy unmasks a positive biological association ($r = +0.1845$, $\rho = +0.2180$, $\log_{10}(p) = -123.8$), which was previously obscured by library depth confounding in unrarefied raw plug-in entropy ($r = +0.0083, \rho = +0.0472$). The strongest remaining covariate association for `entropy_rarefied` in sample1 is with `percent.mt` ($r = +0.3291$, $\rho = +0.2981$) — larger in magnitude than either depth term, and opposite in sign to the raw plug-in metric ($r = -0.1896$). Mitochondrial genes are excluded from the entropy matrix, so this is not self-correlation; it is recorded here as an open covariate to characterise before Stage 4 treats the metric as depth-clean.
The mechanism that had to be excluded is that both the negative depth correlation and the positive MT correlation are one artefact: a degraded, high-MT spot has flatter, more ambient-like non-MT signal, which at fixed $D$ reads as higher diversity, and shallow spots are the high-MT ones (cohort $\rho = -0.41$ between depth and MT, Stage 0). Since the entropy–stemness association appeared in the same step that introduced the MT association ($r = +0.008 \to +0.184$), the association could have been entirely quality-driven. The confound control shows it is not, in sample1:
- `Stemness_Score1` is only weakly coupled to quality: $r = +0.0942$, $\rho = +0.0647$ vs `percent.mt`; $r = -0.0762$, $\rho = -0.1284$ vs $nCount$; $r = -0.0728$, $\rho = -0.0886$ vs $nFeature$. The score does not track degradation the way the entropy metric does.
- Controlling for both `percent.mt` and $\log(nCount)$ attenuates the association by 16% at most and leaves it far from zero: $r = 0.1845 \to 0.1555$ ($\log_{10} p = -62.8$), $\rho = 0.2180 \to 0.1930$ ($\log_{10} p = -96.7$). Controlling for `percent.mt` alone gives $r = 0.1632$, for $\log(nCount)$ alone $r = 0.1670$.
- The association is unchanged in the clean subset: `percent.mt < 10` retains 11,400 of 11,566 spots (98.56%) and gives $r = +0.1830$, $\rho = +0.2152$.
- The direction is not carried by the high-MT spots. In the 166 spots at `percent.mt` $\ge 10$ the association reverses ($r = -0.2491$), and across quartiles of `percent.mt` it is positive throughout and weakest in the cleanest quartile ($Q1$: $r = +0.0946$; $Q2$: $+0.2489$; $Q3$: $+0.1837$; $Q4$: $+0.1657$), which is the opposite of the gradient a degradation artefact would produce.

Independently, partialling $\log(nCount)$ out of the *unrarefied* plug-in metric moves its null result onto the rarefied one ($r = +0.0083 \to +0.1594$, $\rho = +0.0472 \to +0.2013$). Rarefaction and regression adjustment are different corrections for the same depth confound and they agree, which is evidence that the association is a property of the data rather than of the estimator.
**Alternatives considered / rejected:** Storing formatted character strings in CSVs was rejected because it saturated small $p$-values at `"0.00e+00"`, preventing quantitative ranking and meta-analytic pooling. `ppcor::pcor.test` was rejected for the partial correlations: it computes the same residualisation-based quantity, and adding a package to the pinned environment for ~20 lines of base-R arithmetic is not worth the dependency. Using `percent.mt < 10` as the only subset check was rejected as too weak to discriminate — sample1 has a median `percent.mt` of 3.36% and the cut removes only 1.44% of spots, so the "clean subset" is very nearly the full set; the quartile strata are what make part (c) informative. Regressing on raw $nCount$ rather than $\log(nCount)$ was rejected because depth is right-skewed and enters the support ceiling logarithmically, so the linear covariate under-adjusts.
**Status:** implemented

## D4 — Stemness gene reference / scoring
**Script:** `analyze_stemness.R`
**Decision:** Spot-level stemness is quantified using Seurat's `AddModuleScore()` on the SpaNorm-normalized `data` layer with a curated panel of meningioma and neural stemness markers (`PROM1`, `SOX2`, `POU5F1`, `NANOG`, `NES`, `CD44`, `MYC`). Prior to scoring, per-gene spot detection rates, mean expression counts, and detection levels are calculated and saved to `results/stemness_analysis/<sample_name>_stemness_marker_detection.csv`. Variable marker panels are accepted across samples due to Visium dropouts, and the exact subset of detected vs missing markers is logged in `results/stemness_analysis/<sample_name>_stemness_qc.csv`. Random seed 23 (`set.seed(23)`) is initialized before scoring to ensure deterministic control feature binning and sampling. Stemness module score (`Stemness_Score1`) is correlated against `entropy_rarefied` and saved in `results/seurat_objects/<sample_name>_spatial_obj.rds` for downstream marker discovery (`find_entropy_markers.R`).
**Rationale:** Evaluating expression of established stem cell transcription factors and surface markers provides a validated baseline reference for stemness in meningioma. Pre-evaluating marker detection ensures that researchers can verify whether module scores reflect multi-gene programs or are predominantly driven by single robust markers. Module scoring operates on SpaNorm-normalized expression to ensure spatial smoothing and sequencing depth adjustment.
**Alternatives considered / rejected:** Pluripotency transcription factors including Oct-4 (`POU5F1`) and `SOX2` are known to be present in non-stem tumor cells and normal meningeal cells, which limits their specificity for cleanly distinguishing stem from non-stem populations. Measured detection rates in sample1 reveal heterogeneous expression: robust ($\ge 50\%$ of spots) `CD44` (80.0%), `MYC` (74.4%), `NES` (60.1%); moderate (5–50%) `SOX2` (18.7%), `POU5F1` (14.3%), `PROM1` (11.8%); low (1–5%) `NANOG` (2.1%). These tiers describe detection frequency only; `POU5F1` and `PROM1` remain subject to cross-hybridisation / pseudogene verification in Stage 5. Candidate supplementary markers include `FZD9`, `GFAP`, `VIM`, `SSEA-4`, `CD73` (`NT5E`), and `CD105` (`ENG`).
**Status:** implemented
**Review notes:** Added per-gene detection evaluation (`_stemness_marker_detection.csv`), per-sample marker presence tracking (`_stemness_qc.csv`), deterministic control gene selection (`set.seed(23)`), and unified correlation reporting against `entropy_rarefied` via `R/entropy_correlation.R`.

## D5 — Cohort Gene Universe
**Script:** `build_gene_universe.R` (calls `R/gene_universe.R`)
**Decision:** The cohort gene universe is constructed across all 22 Visium samples by identifying all features with at least 1 count in at least 1 on-tissue spot in any sample, then excluding the retired `DEPRECATED_ENSG*` probe rows (`results/cohort_qc/gene_universe.csv`). Features in this universe are loaded via `load_gene_universe()` in `R/gene_universe.R` and used to filter raw matrices prior to per-sample filtering. Matching against a `Seurat` object is done on Seurat-sanitized names (`sanitize_feature_names()`), because `CreateSeuratObject()` rewrites underscores to dashes in feature names.
**Rationale:** Stage 0 chemistry verification demonstrated that all 22 samples share identical probe chemistry (Visium V5 Slide, CytAssist 11mm grid, 37,082 GRCh38 feature rows). Across the entire cohort of 22 samples:
- **19,015 features** (51.28%) carry $\ge 1$ count in $\ge 1$ sample on-tissue.
- Of those, **480 features** are retired `DEPRECATED_ENSG*` probe rows carrying 0.85% of cohort counts. They are excluded from the universe: they are artefacts of panel revision, not interpretable gene-level measurements.
- The gene universe is therefore **18,535 features** (49.98% of the grid), of which 18,532 are distinct symbols — three symbols appear twice in the GRCh38 feature list, and `make.unique()` renames the second copy in the loaded object but not in the universe file, so that copy is dropped.
- **18,067 features** (48.72%) are structurally zero across all 22 samples because no probe in the CytAssist Human Transcriptome panel targets them.
- **18,453 universe features** (99.56%) are detected in all 22 samples.
Because the probe panel is identical by construction, the gene universe is fully deterministic without requiring ad-hoc union rules or union-negotiation across samples. Filtering to this universe removes uninformative zero-probe rows upfront, standardizing the feature space across the cohort.
The universe is built over **all 22 samples, including the 6 excluded by D6**, and `build_gene_universe.R` calls `all_samples()` rather than `cohort_samples()` for that reason. This is deliberate. The union is permissive by design, so features contributed only by the degraded samples are rare everywhere and contribute negligibly to entropy at $D = 2000$; rebuilding on 16 would shrink the feature space and invalidate the sample1 figures recorded in D1 and D2 for no measurable gain. The gene universe is reference data, not a biological result, and is the one place in the pipeline where the full slide set is used.

**Alternatives considered / rejected:** Retaining all 37,082 GRCh38 rows was rejected because it distorts gene retention QC denominators and inflates memory consumption. Defining the universe per-sample was rejected because it causes inconsistent feature sets across samples in downstream cohort comparisons. Retaining the `DEPRECATED_ENSG*` rows was rejected on interpretability grounds. Rebuilding the universe on the 16-sample D6 cohort was rejected per the paragraph above.
**Status:** implemented
**Review notes:** Implemented `build_gene_universe.R` and `R/gene_universe.R`. Emitted `results/cohort_qc/gene_universe.csv` with gene IDs, gene names, cohort total counts, per-sample detection frequencies, and the `is_deprecated_probe` flag.

Verification note: the first implementation defined the universe as all 19,015 detected features and matched on the raw h5 names. Because every deprecated probe name contains an underscore and Seurat rewrites underscores to dashes on load, all 480 deprecated rows failed to match and were dropped *by accident* rather than by decision — which is why the first sample1 QC table reported `Genes_In_Universe = 18,532` against a documented universe of 19,015. The exclusion is now explicit in `build_gene_universe.R` and matching is name-sanitized in `filter_by_gene_universe()`, so the retained feature set is unchanged (18,532 features in sample1) but is the stated one rather than a coincidence of name mangling.

## D6 — Cohort sample inclusion/exclusion criteria & software metadata
**Script:** `check_cohort_chemistry.R` (Stage 0)
**Decision:** Out of the 22 sequenced Visium spatial transcriptomics samples, 6 samples are excluded from downstream biological analysis due to tissue degradation and severe mitochondrial read contamination (mean spot $\text{\%MT} \ge 10\%$):
- `sample2`: mean spot MT = 11.50%, total counts = 33.6M, median depth = 1,784
- `sample3`: mean spot MT = 11.52%, total counts = 148.3M, median depth = 4,530
- `sample12`: mean spot MT = 10.54%, total counts = 89.9M, median depth = 9,834
- `sample16`: mean spot MT = 14.74%, total counts = 25.8M, median depth = 2,498
- `sample19`: mean spot MT = 10.80%, total counts = 133.4M, median depth = 9,185
- `sample20`: mean spot MT = 16.84%, total counts = 36.6M, median depth = 2,995

The remaining 16 samples form the primary analysis cohort (`sample1`, `sample4`, `sample5`, `sample6`, `sample7`, `sample8`, `sample9`, `sample10`, `sample11`, `sample13`, `sample14`, `sample15`, `sample17`, `sample18`, `sample21`, `sample22`), exhibiting clean transcriptomes with mean spot $\text{\%MT}$ between 3.42% and 8.73%.

**Space Ranger Version Note:**
All 22 raw sample HDF5 files contain the embedded root attribute `software_version = "spaceranger-2.0.1"`, whereas the GEO series metadata annotation indicates Space Ranger 4.0.1. We explicitly note this metadata discrepancy: all upstream probe alignment, demultiplexing, count matrix generation, and fiducial image alignment files were generated using Space Ranger 2.0.1 per the file-level attributes embedded in every sample HDF5.

**Rationale:** High mitochondrial percentage in Visium FFPE spatial transcriptomics indicates cellular membrane lysis, loss of cytoplasmic mRNA, and severe tissue degradation. Degraded spots lose structured, cell-type-specific transcriptional programs and present flat, ambient-like non-mitochondrial RNA profiles. In downsampled diversity estimation at fixed depth $D$, such flatter distributions mechanically inflate rarefied Shannon entropy, acting as a profound technical confounder. Establishing an explicit quality cutoff at mean spot $\text{\%MT} < 10\%$ before running cross-sample biological inference protects against false-positive entropy–stemness correlations driven by tissue degradation.

**Alternatives considered / rejected:**
1. *Post-hoc sample exclusion based on stemness correlation:* Strongly rejected. Excluding samples after observing their biological correlation produces severe selection bias and invalidates statistical inference. Quality exclusion must be frozen upfront based strictly on orthogonal technical quality metrics (Stage 0 %MT).
2. *Exclusion based on sequencing depth alone:* Rejected because several moderate-depth samples (e.g., sample4, sample21) have low mitochondrial read percentages ($\text{\%MT} \le 8.3\%$) and intact spatial tissue morphology, yielding valid biological data when standardized at $D = 2000$.
3. *Ad-hoc spot-level MT trimming without sample exclusion:* Rejected because heavily degraded samples (where >50% of spots have high MT and total sample MT is elevated) suffer from pervasive ambient background contamination across all capture spots.

**Second gate — spot retention at $D = 2000$.** The depth gates in D1 drop each sample's shallow tail, and that tail is not the same size everywhere: the Stage 3 sweep measured 99.63% on-tissue retention for sample1, 81.48% for sample4 and 68.13% for sample21. Dropped spots are the shallow ones, which are spatially clustered rather than scattered, so each sample enters Stage 4 with a differently-holed hex lattice. A sample that has lost a third of its tissue area is not directly comparable to one that lost none.

A minimum retention of **60% of on-tissue spots** (`COHORT_MIN_RETENTION_PCT` in `R/cohort.R`) is therefore frozen *before* the cohort run, for the same reason the %MT threshold is: a retention floor chosen after seeing entropy–stemness correlations is a selection-bias generator, which rejected alternative 1 forbids. Projecting from the `nCount_q05_postqc` / `nCount_q10_postqc` columns of `chemistry_check.csv`, the expected losses among the 16 are sample21 ≈ 32%, sample4 ≈ 19%, sample7 ≈ 13%, and under 10% for the remaining thirteen — so no sample is expected to fail, and the floor is a guard rather than a prediction. `check_cohort_retention.R` applies it against the per-sample QC tables after the run and writes `results/cohort_qc/retention_gate.csv`.

**Enforcement.** The exclusion is not advisory: `R/cohort.R` holds the frozen list as `COHORT_EXCLUDED`, and `analyze_entropy.R` and `analyze_stemness.R` both take their sample set from `cohort_samples()` and resolve their command-line argument through `resolve_target_sample()`, which refuses a D6-excluded sample unless `allow_excluded = TRUE` is passed for an explicitly diagnostic run. `check_cohort_chemistry.R` and `build_gene_universe.R` still cover all 22 by design — the first produces the criterion, the second is reference data (D5).
